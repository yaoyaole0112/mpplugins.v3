# 通知合并

短时间窗口内合并剧集入库和同类通知，减少 Telegram 等渠道的消息刷屏。

- 默认等待 60 秒，可在插件设置中配置 1–3600 秒；每条同组通知到达后重新计时
- 剧集入库通知按消息类型、剧名、年份和季聚合，不同剧集或季不会混合
- 同时识别标题季集号和正文 `✅ 已入库 · S01 E01`，适配自定义入库模板
- 摘要压缩实际存在的集数范围，不会把缺集补成已入库：E01、02、03、05、06 显示为 `E01-03,E05-06`
- 类型、质量去重展示，主演去重合并，文件大小统一单位后求和；不依赖 AI，不向外部服务上传通知内容
- 不同渠道、目标用户、来源和通知路由范围分别聚合，保持原消息隔离
- 未知正文、失败通知、缺失或无法解析的部分大小回退为原文合并，避免丢失重要信息或给出错误总大小
- 单条消息保持原文；交互消息和富文本/结构化消息不进入聚合队列
- 非剧集通知按完整标题合并
- 原始消息仍保留在 MoviePilot 消息中心

启用时需要同时打开宿主的插件实例开关和插件表单内的“启用通知合并”。

## 线上安装

在 MoviePilot 插件市场添加仓库 `https://github.com/yaoyaole0112/mpplugins.v3`，安装“通知合并”（MessageMerge）。
完整发布包自带通知拦截模块，不需要手工复制文件、挂载本地补丁或配置本地插件仓。
若已有其他通知插件加载共享拦截链，会复用同一条链，避免重复包装发送入口。
更新请通过插件市场操作，保留原有通知类型和发送范围配置。

```text
🗂 类型：国产剧
📑 质量：WEB-DL HDR 2160p

👤 主演：刘诗诗、胡先煦、李乃文、李沁、黄小蕾

```
