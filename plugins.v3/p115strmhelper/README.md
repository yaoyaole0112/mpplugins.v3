# 115网盘STRM助手（MoviePilot V3 适配）

## 3.0.7 更新说明

- 修复增量同步导出目录树遇到读取异常时，底层生成器在清理阶段报 `generator ignored GeneratorExit`，导致实际故障原因被隐藏的问题。
- 显式关闭和清理导出文件；同步失败时记录原始异常及堆栈。若仍出现连接超时或 115 接口错误，请根据新的日志排查网络或服务端情况。

## 3.0.6 更新说明

- 历史查询使用新版宿主的同步查询事务执行器，避免无显式会话时出现 `'NoneType' object has no attribute 'execute'`；兼容旧版宿主已有会话及两版标题通配查询接口。
- 生活事件删除前使用严格存储查询。401/405、超时或其他查询异常时保留本地 STRM、目录、数据库和整理历史，不再把查询失败误判为网盘文件不存在。
- 不支持严格查询接口的旧宿主暂停生活事件同步删除并提示日志；其他监听、生成及整理功能不变。此版本不绕过 115 风控或修复过期 Cookie，也不会自动恢复此前已删除的文件。

## 3.0.5 更新说明

- 补齐旧宿主挂载补丁缺少的 `_transfer_validation_error` 接口，遵循当前 MoviePilot 的音乐结构、识别状态及分类检查，避免整理运行时 AttributeError。
- 仅在宿主没有该接口时添加；停止插件时移除自身补丁，完整保留 3.0.4 的仓库迁移修复。

## 3.0.4 更新说明

- 完整保留 3.0.3 的前端资源、目录浏览、405 熔断、整理接管、字幕关联及媒体同步删除修复，无需本地脚本持续回写插件文件。
- 合入生活事件连接失败的退避重试，失败时保留游标，恢复连接后继续处理。
- 锁定已验证的 concurrenttools / iterutils 依赖版本，避免 p115client 导入 threadpool_map 失败。
- 插件内置旧宿主音乐上下文 storage/batch_mtype 兼容补丁；仅在宿主缺少参数时启用，支持新版接口的宿主保持原实现。停止插件时恢复本插件安装的补丁。
- 此修复不打包整份 MoviePilot 核心文件；服务器上与 115 插件无关的音乐分类、H&R 等自定义补丁不属于插件发布内容。

### 从本地版本迁移

保留插件配置、数据库和 Cookie，不要卸载插件。先关闭所有针对 P115StrmHelper 的本地仓库候选和启动脚本回写，然后从本仓库重新安装。确认版本为 3.0.7、运行来源为本仓库，重启后再次确认。不要把 `/config/plugins`、数据库、Cookie、日志或环境文件上传到仓库。

以后同时更新插件源码和根目录 `package.v3.json` 的 P115StrmHelper 版本，保持 `release=false`，提交前端变更时包含 `dist/`。MoviePilot 从本仓库检查更新，不再读取开发目录。

## 3.0.3 更新说明

- 修复批量转存时生活事件只读取最新一页（最多 1000 条），导致较早文件可能遗漏整理的问题：按接口游标分页拉取，缺少游标时使用偏移量翻页。
- 分页失败或页码未推进时保留原监听游标，避免漏掉尚未处理的文件；新增分页回归测试。
- 升级不会自动重放过去已经跳过的事件。请检查待整理目录及目标媒体库，并通过「手动网盘整理」补扫仍留在待整理目录中的文件。

基于 DDSRem 的 P115StrmHelper，适配 MoviePilot V3：

- 整理接管改为 V3 `_plan_checkpoint_and_execute` 拦截
- 历史查询改用 `media_source` / `media_id`
- 恢复 Vue 联邦 `dist/`，本地目录浏览兼容 V3 `storage/list` 包装，并优先走插件 `browse_dir`
- 增量同步 405 风控熔断与 proapi 优先

已被旧版监听游标越过的文件不会因升级自动重放。请在插件的「手动网盘整理」中对仍位于待整理目录的文件所在文件夹发起补扫；补扫前先检查目标媒体库中是否已有同集，尤其留意自动删除低质量源文件的设置。

安装：MoviePilot 插件市场添加仓库 `https://github.com/yaoyaole0112/mpplugins.v3` 后搜索「115网盘STRM助手」。本仓库未提供 GitHub Release 压缩包，请使用源码安装（`release=false`）。
