## 当前功能说明（2.10.46）

本插件在 MoviePilot 内提供侧栏页面及插件弹窗两种入口；两处共用配置和后端功能。以下为当前行为说明，后续的逐版本记录用于描述当时变更，旧版本记录不代表当前限制。

- **Telegram 交互结果**：执行中、完成、失败或取消直接更新原确认通知；结果正文不重复包含标题，无需再查找下方另一条通知。网页发起或确认与 TG 命令保持同步，一次性确认、有效期、管理员权限及删除前复核不变。更新前已发出的通知若没有可编辑的消息 ID，网页执行仍会发送一次独立结果；TG 点击确认时可补记原消息。

- **订阅监控与缺集检测**：订阅/关键词监控按配置筛选频道消息并转发；缺集检测读取 Emby 与 TMDB 信息，可筛选服务器、媒体库和剧集，显示在播状态、缺失集及复查状态，并按设置执行订阅或资源搜索。缺失集结果表格可横向滑动；跳过检测会加入持久化跳过列表。
- **媒体清理**：按已保存规则扫描媒体库的重复/低质版本；并列最佳时优先比较 MoviePilot 当前重命名规则，仍并列则按本地 STRM 修改时间择优。命名服务异常时采取保守保留，不保证每组一定自动删除到单一版本。
- **数据补全**：支持电影及剧集的单项和批量补全。主数据源可选 TMDB 或豆瓣优先，并按可确认匹配从豆瓣、电视猫、百度百科补充中文演职资料；剧集分集资料支持电视猫优先、百度百科兜底。AI 翻译使用通用补全设置且需 MoviePilot LLM 可用，未获得可靠译文时保留原文。入库自动补全对电影补本片、剧集分集入库补所属整剧；分集演职同步及分集图片处理仅适用于剧集。
- **分集图片修复**：统一检测并修复缺图、疑似偏色及尺寸异常图片；单剧与批量入口使用同一修复逻辑。覆盖已有预览图需按界面选项启用，尺寸优化目标为 1280×720；检测算法可能产生误报，修复前可检查结果。
- **115 文件管理**：支持无效 STRM 资料扫描/隔离、清理文件预览与确认、回收站清空及目录转存。清理文件确认可在媒体增强页面或符合权限要求的 Telegram 管理员私聊按钮操作。转存规则逐条选择移动或复制；复制只处理此前未成功复制的新增项目，清理复制记录后可重新复制全部项目。规则可手动执行或按设置的间隔轮询执行。
- **安全与任务行为**：115 操作共用协调队列并限速；删除、移动、复制等提交请求在结果不确定时不会自动重放。清理与回收站清空需显式配置定时任务，具有不可逆风险的操作应先核对预览和确认范围。

MoviePilot Bot 支持 `/cleanup`、`/cleanfiles`、`/cleartrash`、`/cleandupes` 和 `/ememove`。前四项数据/文件管理命令中的 `/cleanup`、`/cleanfiles`、`/cleartrash` 及转存命令 `/ememove` 均先扫描或预览，再向发起命令的 Telegram Bot 管理员私聊发送确认/取消按钮，无需返回网页重新查询；网页可接续同一待办。确认后原通知切换为单一执行中状态，完成后改为完成状态；失败、取消或过期不保留可执行按钮。确认 30 分钟有效、仅执行一次，空目录或预览失败不生成确认。命令回复不受常规通知开关限制，也不广播到其他 Bot。`/cleandupes` 按已保存的定时媒体库范围扫描低质版本，仅向发起命令的 Telegram Bot 管理员私聊发确认按钮；确认 30 分钟内有效，核对当前扫描结果后才清理，完成摘要仅回复原 Bot。定时清理的完成通知使用 MoviePilot「插件」类型。手动扫描媒体库与定时清理范围独立；规则可在检测扫描的清理规则弹窗设置。复制模式只复制新增项目，并可在文件转存页面清理复制记录后重新复制全部项目。

命令回复严格使用 MP 命令事件携带的 Telegram 渠道来源（Bot 配置名称）；来源缺失时拒绝发送，避免向所有 TG Bot 广播。Bot 命令触发的文件转存仅回复发起命令的 Bot，不额外发送全局工具通知。订阅监控解析转发 Bot 时，Bot API 的 `getMe` 请求沿用 MP Telegram 通知渠道的 HTTPS 代理配置；Telethon 用户账号连接仍由自身客户端负责。Bot 用户名解析结果在当前监控会话内缓存，Token 更新后重新解析，不记录 Token 内容。
