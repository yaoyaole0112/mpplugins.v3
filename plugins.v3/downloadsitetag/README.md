# 下载任务分类与标签

基于官方插件适配 MoviePilot V3 音乐下载。自动给下载器任务打站点标签、媒体名称标签，并按媒体类型设置 qBittorrent 分类。

## 分类

| 媒体类型 | 默认分类名 |
| --- | --- |
| 电影 | 电影 |
| 电视剧 | 电视 |
| 动漫（电视剧且命中动漫 genre） | 动漫 |
| 音乐 | 音乐 |

官方 3.2.0 只有电影 / 电视 / 动漫。V3 把音乐作为独立媒体类型后，音乐任务在开启分类时会被当成电视剧。3.3.0 按 `MediaType.MUSIC` 写入音乐分类，并避免读取音乐元数据上不存在的 `genre_ids`。

## 用法

1. 在 qBittorrent 中预先创建对应分类，或允许插件在设置失败时自动创建。
2. 启用插件，按需打开「自动分类」「站点标签」「媒体名称标签」。
3. 音乐分类名称默认是 `音乐`，可改成下载器里已有的分类名。

Transmission 仍只支持标签，不支持分类。
