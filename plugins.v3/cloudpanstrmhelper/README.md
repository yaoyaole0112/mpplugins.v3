# 网盘STRM助手 CloudPanStrmHelper

仿 115 网盘 STRM 助手的 MoviePilot 插件：全量/增量 STRM 同步、整理事件监控、网盘目录整理。

通过 MoviePilot `StorageChain` / `TransferChain` 工作，可对接 `115网盘Plus`、`CloudDrive储存`、`123云盘` 等已安装的存储模块。

## 功能

- 全量 / 增量 STRM 同步，路径格式：`本地STRM目录#网盘媒体目录`
- 整理完成事件监控，自动生成 STRM，可选刮削和媒体服务器刷新
- 扫描网盘整理目录，交给 MoviePilot 目录整理入库
- STRM URL：插件 302、转交 115 助手、直链、自定义模板

## 安装

在 MoviePilot「插件仓库」添加：

`https://github.com/yaoyaole0112/mpplugins.v3`

然后安装「网盘STRM助手」。存储名称必须与 MoviePilot 存储模块名称完全一致。

115 播放建议将 STRM URL 模式设为「转交115助手」。
