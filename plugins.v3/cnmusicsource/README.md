# 华语音乐识别

MoviePilot V3 音乐整理默认只走 MusicBrainz。华语新歌、游戏 OST、抖音热歌经常不在 MusicBrainz / TheAudioDB / 豆瓣音乐里，自动整理就会失败。

本插件把 QQ 音乐、网易云音乐注册成可选手动数据源，并在 MusicBrainz 未识别到远端身份时自动回退匹配。

## 用法

1. 启用插件（默认开启自动回退）。
2. 手动整理时数据源可选「QQ音乐」或「网易云音乐」。
3. 数据源保持「自动」时：先查 MusicBrainz，失败后再查 QQ / 网易云。
4. 音乐目录如果开了「按类别分类」，识别成功后会走分类规则；识别失败时不要指望 TMDB 给音乐分类。

## 说明

- 只查询公开搜索/详情接口，用于元数据识别和整理，不提供下载。
- 网易云对部分腾讯系新歌、游戏主题曲覆盖较差，QQ 音乐通常更全。
- 自动回退要求曲名命中，且文件名里解析出的艺人也命中，避免同名翻唱误匹配。
- 手动选择 QQ / 网易云时，即使标题被当成影视种子（如 `许嵩-梦游计 2012 WEB-DL FLAC-HHWEB`），也会先收成「许嵩 - 梦游计」再检索专辑/单曲。
- 合奏标签会拆开匹配：`薛之谦 韩红`、`古巨基;刘涛`、`Jay Chou (周杰倫)` 只要命中其中一位即可。
- 识别成功后，若本地专辑是「合集1 / 群星」这类占位名，整理路径会改用 QQ / 网易云的真实专辑名。

## 1.0.5 修复与部署注意

- 保留核心已解析的音乐标签，避免重新解析纯曲名时丢失艺人、专辑及其他标签。
- 显式指定专辑或录音时只匹配对应实体，自动回退也保留核心传入的实体类型。
- 本插件不需要覆盖 MoviePilot 核心文件。若曾挂载旧版 `app/chain/transfer/filter.py`，升级核心后应撤销旧挂载并重建容器；仅升级本插件无法修复旧核心补丁导致的 `release_by_main_key` 缺失异常。
- 回归测试需在具有 MoviePilot V3 运行依赖的环境执行：`python -m unittest discover -s plugins.v3/cnmusicsource/tests -v`。
