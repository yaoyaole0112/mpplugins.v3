# 剧集缺集检测订阅

基于 Emby 全局剧集清单与 TMDB 季集数据进行比对，可按服务器和媒体库限定检测范围，并将缺失季自动添加到 MoviePilot 订阅。

## 配置说明

- **仅检查已有季缺失**：开启时，只检查 Emby 中至少已有一集的季度；关闭时也会报告整季缺失。
- **缺失处理方式**：支持仅记录、添加到订阅、标记为存在。建议首次运行使用“仅检查记录”。
- **电视剧媒体库白名单**：从 Emby 实时读取可用电视剧媒体库，支持勾选多个；留空表示全部。
- **Emby 媒体服务器名称白名单**：从 MoviePilot 配置中读取 Emby 服务器，支持勾选多个；留空表示全部。
- **执行周期**：标准 5 段 cron 表达式，默认每天 03:35 执行。

检测结果可在插件详情页查看或导出 CSV。订阅以 TMDB ID 和季度为单位创建，已存在的订阅由 MoviePilot 的 `exist_ok` 机制处理。
