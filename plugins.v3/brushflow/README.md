# 站点刷流

当前版本为 V6.4.3。任务页面只保留“规格去重”开关与全局规则入口；频道监听与同规格去重窗口集中配置字段、在队去重、包内去重、整包处理和身份策略。任务开启后才参与这些资源级规则。

## V6.4 资源去重

- **规格去重开关**：新建 / 编辑任务 → 基础与调度 → “规格去重”，新任务默认开启。只控制本任务是否参与频道、账本、在队和包内资源去重、身份待核验、完成证据登记及下载中频道重复取消。任务本身的媒体类型、最近播出、促销、包含 / 排除等选种规则继续独立生效，限额、标签、分类、发布、删种及 H&R 保护不变。
- **关闭规格去重**：跳过上述资源级规则，不登记新的完成证据，也不让本任务的在队文件阻拦其他任务。已有长期账本不清空，其他开启去重的任务仍可使用历史有效证据。原有 Hash 防重有效，因此关闭时允许跨站下载内容相同但 Hash 不同的种子。
- **全局规则、任务参与**：任务开关和对应全局策略同时满足才执行。频道监听开关只控制频道同步和下载中频道取消，不是账本、在队或包内去重的总开关。关闭某个任务的规格去重不取消或删除其已有下载。
- **在队去重**：“排除已入队的同规格资源”默认开启，控制资源占位、在队匹配及历史在队文件补查；关闭后不创建新占位，也不使用旧占位拦截其他资源，不清空长期完成证据。重新开启后按实际下载器状态恢复核验。
- **整包处理**：默认“逐文件排除，仅下载剩余文件”；可选“存在不合格文件则排除整包”。后者在任一候选视频被资源去重、缺规格或严格身份策略排除时不添加整个种子，不会通过关闭分集筛选而把重复集全部下载。此策略只处理原有选种规则剩余的候选，不改变最近播出规则独立的分集选择，也不改变已入队任务的取消安全保护。
- **按勾选字段判断**：重复键为“媒体类型 + 核验后的 TMDB ID + 季集号（电影无季集号）+ 当前勾选字段组合”。仅勾分辨率时，同一集的 1080p HDR 完成后，1080p SDR / 不同编码等均排除；首个 4K 仍可下载，完成后其他 4K 均排除。`4K/UHD/2160p` 是同一分辨率。其他字段同理；多选时所有勾选字段必须同时相同才判重复，例如同时勾分辨率和特效，则 1080p HDR 与 1080p SDR 可各留一份。未勾选字段完全忽略，候选缺少已勾字段按全局策略处理，未知值不是通配符。未勾选任何字段时不执行规格匹配或缺规格过滤。电影和剧集使用独立身份空间，即使 TMDB ID 数值相同也不合并。
- **旧配置迁移**：旧分享且未关闭去重的任务迁移为开，旧纯刷流或模式为关闭的任务迁移为关；旧“每集仅一份”模式也归一为按勾选字段判断。显式新开关优先，不再按任务名称或分类重判。只有没有任何用途 / 模式 / 新开关的更早版本配置才在首次升级时根据原“分享”名称或分类初始化开关。
- **同包去重**：“排除同一种子包内的同规格重复文件”默认开启，按种子文件清单顺序保留第一份符合其他规则的文件，不额外做画质排名；关闭只停止包内互比，频道、账本及已开启的在队匹配不受影响。多集共用一个物理文件时，只有包含的所有集都已被频道、账本、在队或同包证据覆盖才排除，不能拆分文件内部的单集。只覆盖部分集时仍需下载整文件。

长期账本把**已同步频道的发布证据**和**开启规格去重的任务实际勾选且已完成的文件**持久保存，不受频道记录 72 小时保留期、任务删除或重启影响。待添加、下载中、失败添加只形成临时占位，不提前当作完成证据。首次升级导入目前仍保留的频道记录；现存已完成任务在后续正常检查时按实际文件补记，尚未核验的文件后续重试。升级前已删除、归档且不再可读取文件的历史下载无法凭标题完整补建。

频道设置中的“长期账本 / 身份待核验”可分页查看证据；“移除长期证据”会留下撤销标记，避免同一条证据立即从旧频道缓存重新导入，但当前频道和仍在队的任务仍可拦截该资源。移除某条记录不等于对整部影片 / 全剧解除去重，其他有效证据仍参与。账本无自动过期；待核验列表最多 5000 条，只记录必要字段，不保存下载链接、passkey 或原始消息正文。

严格身份策略优先采用文件或种子标题明确的 TMDB ID，其次采用手动别名绑定，最后采用 MoviePilot 的正式名称 / 别名、类型和年份核验；不把模糊相似标题直接认作同一作品。电影需要精确名称、电影类型和已知年份一致；剧集沿用中文名称冲突、季号及年份保护。电影和剧集有独立的别名绑定输入框。修改绑定会清除缓存并更新由绑定推导的在队和账本身份，不覆盖文件显式 ID；撤销或冲突的绑定证据不再参与匹配。文件名大小写、标点、全半角归一化，`4K/UHD/2160p`、`FHD/1080p`、`AVC/H.264`、`HEVC/H.265` 等规格采用统一表示。

开启规格去重并使用严格身份策略时，身份不明或剧集组无法核验标准季集号会进入待核验列表而非按“非重复”下载；没有可核验文件清单的磁力链接也暂不添加。配置别名后，候选在后续正常选种重试时重新核验，待核验列表本身不是保证自动重放所有历史候选的下载队列。频道监听关闭时，任务规格去重仍会使用账本、在队和包内证据。

配置入口：任务编辑页开启“规格去重”，点击“设置全局去重规则”；也可从工作台右上角飞机按钮进入“频道监听与同规格去重”。规则为所有开启规格去重的任务共用，关闭频道监听仍可修改并用于账本、在队及包内去重。“资源身份未确认时”默认等待核验；旧任务身份策略一致时迁移为相同的全局策略，不一致时采用严格等待核验，显式全局配置始终优先。任务配置不再保存独立的身份策略。

例如只勾分辨率，A、B 两站任务均开启规格去重，A 站已完成某剧 `S01E05 1080p HDR`，B 站的 E05–E07 1080p 分文件包只选 E06、E07；同一包再有另一份 1080p E06，只保留第一份。首个 4K E05 仍可下载，之后其他 4K E05 都排除。A 站任务删除或重启后仍由长期账本保护。尚在下载的同规格先临时占位，避免多个站点同时下载；确认添加失败或已删除后释放占位，不当作已完成。关闭规格去重的任务不受该资源去重限制。

以下 V6.3 规则描述中的“只比较勾选规格”由任务规格去重开关控制。下载中取消沿用每分钟有限批次回查及暂停复核流程，仅对开启规格去重的任务按勾选字段匹配，仅使用近 72 小时频道证据；不因自己的完成账本去取消同一任务。不会追溯删除已经完成的重复文件，也不跨 MoviePilot 实例协调。

站点刷流 V5 使用 Vue 模块联邦提供任务工作台。每项任务独立绑定一个站点和一个下载器，并拥有自己的调度周期、选种与删种规则、托管记录、统计和运行诊断。

全局设置支持限制所有任务合计的保种体积、同时下载任务数和总上传下载带宽；任务编辑器中的运行限额仍只约束当前任务。限额留空或设置为 `0` 表示不限制。

全局动态删种会汇总所有启用任务的做种体积。单值阈值（如 `100`）在达到 100 GB 后删到 100 GB；区间阈值（如 `50-100`）在达到 100 GB 后删到 50 GB。任务启用动态删种时，其已完成非 H&R 种子会参加全局兜底淘汰；未启用的任务只会在全局阈值触发后按自身删种条件处理。关闭全局模式时，没有独立动态删种阈值的参与任务会恢复为按条件删除。

任务可启用站点账号分享率控制：插件读取 MoviePilot 最新站点统计，当前分享率达到目标时等待，低于目标时自动恢复新增种子。启用控制但尚无可用统计数据时，任务会等待数据更新。

选种规则中的“仅下载最近播出剧集”按中国时区判断，允许三天前（含）至所有未来日期播出的剧集，不以种子发布时间代替播出日期。按包内文件提取季集号，优先读 TMDB 整季日期；缺失时核验单集 API、官方网页，最后尝试精确匹配豆瓣剧名、年份和季号后读取明确的逐集日期。未识别、缺日期或所有请求失败的文件不下载；一个文件含多集时必须全部符合。剧集组不能用默认季集号数据代替。回退查询成功缓存 5 分钟，空结果缓存 1 分钟；日志记录实际日期、来源和日期下限。

右上角飞机按钮打开频道监听设置。监听复用“自动生成ED2K链接”插件的 Telegram 个人账号和 Session 文件锁；需要该插件已运行且个人账号已授权并加入目标频道。正常每 2 分钟增量读取，连续 3 轮所有频道均无新消息后改为每 5 分钟；读到新消息恢复 2 分钟，补读分页、频道未全部轮到或部分失败时不进入空闲降频。宿主每分钟只检查本地下次同步时间，未到时间不连接 Telegram、不读取消息、不写数据库。状态窗口显示当前间隔与下次同步时间；“立即同步”可提前读取，但两次完成后的读取至少间隔 30 秒，并始终遵守账号及网络退避。下次同步时间和限流等待持久化，重新保存设置或插件重载不会绕过限流。

此方案不新增常驻 Telethon 客户端，也不改变 ED2K 发送与登录流程。单频道、无错误且无积压时，活跃期约 30 轮/小时、稳定空闲期约 12 轮/小时；新消息通常在下一轮约 2～5 分钟的同步中发现（宿主调度、网络耗时、限流、账号占用、多频道轮转时可能更久），不是实时推送。频道消息尚未同步时不会参与去重。解析记录仅保存剧名、TMDB ID（若消息提供）、季集号、分辨率、特效、编码、来源、帧率、文件大小、频道及消息游标，原始消息正文不落盘；记录保留 72 小时。

刷流选种条件通过后，插件按种子内视频文件逐集匹配频道记录。剧集身份、季集号和用户勾选的全部规格均匹配时判定重复。**只比较勾选项**：仅勾选分辨率时，同剧同季集且分辨率相同即排除；分辨率不同或没有匹配的频道/入队记录时放行，未勾选的特效、编码、来源、帧率和大小无论缺失还是不同都不影响判断。默认整季包逐文件比较，排除重复或缺少勾选规格的文件，其余文件照常加入；所有候选视频文件均被排除时不下载整包，也可选择存在不合格文件就排除整包。大小按单集文件比较，默认容差 5%；未勾选任何规格项时不执行规格去重和缺规格排除。磁力链接没有可核验文件清单时，开启规格去重且采用严格身份策略的任务暂不添加，兼容放行策略不只凭磁力标题认定重复。

候选规格优先读取视频文件名，其次种子标题，再由站点副标题和标签补缺；副标题不用于认定剧集身份。未写动态范围的 1080p 及以下 H.264/AVC WEB-DL、WEBRip、WEB 资源，且没有 HDR、杜比视界、HLG、高位深或广色域等提示时，按常见 SDR 命名约定比较；这属于命名推断，不是媒体实测，日志明确标记。4K、H.265、10bit 等不确定资源不会这样推断。

V6.3.5 起，“候选缺少勾选规格时”默认选择“排除不下载”，升级后未配置此项也使用该策略。例如勾选分辨率和特效时，无法判断特效的候选排除；仅勾选分辨率时则完全忽略未知特效。可选择“按未命中放行（兼容旧版）”恢复旧行为。日志分别统计“同规格重复”与“缺少勾选规格”，后者不是已发布重复。频道记录缺少勾选规格时，不能据此证明已知规格的候选重复，不会把未知值当通配符。

身份识别保留文件名括号内的中文剧名，再对照 MoviePilot 识别结果的正式名称和别名。V6.3.6 起，中文剧名末尾的“第三季/第3季”等标记仅在季号与视频文件季号一致时移除后比较，基础剧名仍须匹配正式名称或别名；错误季号、其他标题内容不忽略。长英文/罗马音截断只允许至少 8 词、40 个规范化字符、结束于正式别名完整词边界且年份一致的情况；短标题前缀不做模糊合并。中文名称冲突、第一季已知年份冲突以及不同显式 TMDB ID 均不混为同剧；后续季文件年份不必等于剧集首播年。特殊缩写可在“剧名别名绑定（可选）”中每行配置 `剧名别名 = TMDB剧集ID`，它不会覆盖文件中明确的 TMDB ID；修改绑定会清理身份缓存并更新由绑定产生的入队身份。

解析记录列表仍是频道消息记录，频道发帖时间不等于开始下载时间。新增下载前先检查已同步的近 72 小时频道记录，再检查独立保存的 BrushFlow 入队文件记录；两者使用相同的勾选规格和缺规格策略。即使频道尚未发帖或新消息尚未同步，已确认同规格的入队任务也可拦截后续重复下载。

入队占位在调用下载器前原子检查并持久化，只记录最终选中的剧集文件。添加或选集失败时查询真实 Hash，确认任务不存在才回滚；结果不确定或下载器请求失败时暂留占位，防止超时但实际已入队的重复提交。新增任务首次可见前有 5 分钟宽限；之后按下载器分组、最多每 30 秒核验一次，确认已删除后释放。记录在下载器仍存在期间有效，不以频道记录的 72 小时窗口强制过期。升级前已有任务按同名候选按需补查实际文件清单，只采纳 qBittorrent 优先级非零或 Transmission 已选中的文件，不把整季包标题当作已选中全部剧集；历史任务名称没有匹配到或无法读取文件清单时不能补建。

V6.3.7 起可在频道设置中另行开启“取消下载中的频道重复资源”，升级默认关闭。每分钟对最多 50 个托管任务轮转核验，仅使用已同步的近 72 小时频道记录，不额外读取 Telegram。通常在频道下一轮 2～5 分钟同步后，再等一次本地检查；任务较多、繁忙、限流或网络异常时更久，不能保证在快速下载完成前取消。

回查同剧同季集及当前勾选的全部规格，未勾选项忽略；未知信息不作为取消证据。暂停并重新读取实际完成度与文件列表后，仅将未完成的重复视频设为不下载，其他文件的选择和优先级不变；所有仍选中的视频均为未完成重复文件时，移除下载任务但不删除本地数据。已完成视频、H&R 或状态未知、任务归属不独占、共用标签、排除删除标签均受保护。原先运行的部分取消任务恢复下载，原先暂停的保持暂停；失败或结果不明确时保留任务与文件，持久化处理意图后重试。处理中修改频道设置或停用任务时停止后续动作，可能保留暂停状态，日志提示人工检查。取消文件不会清理磁盘上的部分数据。

不处理订阅、手动下载、其他插件实例或其他工具的非托管任务，也不撤回频道消息、不阻止下载完成后的转存或发布。跨任务占位锁仅覆盖同一个 BrushFlow 插件实例；不同 MoviePilot 实例之间需要共用的原子存储才能实现发布前互斥。不能仅凭频道出现两条消息判断某次下载是否由本插件漏过滤。

种子进度及下载完成判断使用下载器的实际文件完成度，累计下载流量独立统计；复用已有文件或跨种时下载量为 0 也可正常显示做种。升级到 V6.1.3 后执行一次“刷新种子”即可更新已有记录。

## 升级兼容

- V3 专用版本依赖 MoviePilot `v3.0.0+`，旧版宿主会在安装和更新前拒绝该版本。
- 首次加载 V5 时，旧版 `brushsites` 会按站点拆分为独立任务。
- 从 V4 直接升级时，原有运行限额和全局动态删种会迁移到新的全局设置；已升级到 V5 的用户可在全局设置中重新设置合计限额。
- 旧版站点覆盖 JSON 会合并到对应任务中。
- 原有种子、归档和未托管数据会按站点迁移到任务命名空间。
- 已有的全局 `刷流` 标签继续识别；V5 新增任务唯一标签，避免多个任务互相接管。V6.0.1 起默认使用按站点名称生成的可读标签（如 `刷流-聆音`），同一站点存在多个任务时请在任务编辑器中设置为不同的下载器标签。
- V5.0.2 会在插件启动、任务检查和任务删除后清理 qBittorrent 中不再被任何种子使用的 `刷流-*` 标签；仍绑定种子的标签不会被强制移除。
- V5.1.0 新增站点账号分享率目标控制，并限制运行诊断长列表在模块内部滚动。

## 前端入口

插件构建产物暴露以下联邦组件：

| 组件 | 用途 |
| --- | --- |
| `AppPage` | 主界面侧栏中的完整刷流工作台 |
| `Page` | 插件详情弹窗 |
| `Config` | 插件配置弹窗 |
| `Dashboard` | 仪表板任务概览 |

侧栏入口由插件的 `get_sidebar_nav()` 注册，可在工作台全局设置中关闭。

## 插件 API

所有接口均使用宿主 Bearer 认证，基础路径为 `/api/v1/plugin/BrushFlow`。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `GET` | `/status` | 获取全局状态、任务摘要与可选站点下载器 |
| `POST` | `/settings` | 更新插件与侧栏入口开关 |
| `GET` | `/channel-dedup` | 获取频道监听配置、状态与最近解析记录 |
| `POST` | `/channel-dedup/settings` | 保存监听频道与去重规格 |
| `POST` | `/channel-dedup/poll` | 提交一次频道增量同步 |
| `GET` | `/resource-ledger?state=ledger&page=1&page_size=20` | 分页查询长期账本；`state=pending` 查询身份待核验 |
| `POST` | `/resource-ledger/forget` | 按证据 `key` 显式移除长期证据 |
| `POST` | `/tasks` | 创建任务 |
| `GET` / `PUT` / `DELETE` | `/tasks/{task_id}` | 查询、更新或删除任务 |
| `POST` | `/tasks/{task_id}/state` | 启用或暂停任务 |
| `POST` | `/tasks/{task_id}/run` | 立即执行刷流刷新 |
| `POST` | `/tasks/{task_id}/check` | 立即执行种子检查 |
| `POST` | `/tasks/{task_id}/clear` | 清除当前任务的独立数据 |

## 构建

在本目录安装依赖后执行 `yarn build`，产物生成到 `dist/assets`，由插件后端的 Vue 渲染模式加载。

后端、前端包和市场索引的版本号须一致，并为该版本填写更新说明。提交构建产物后，从仓库根目录运行 `python scripts/build_brushflow_release.py --output /tmp/brushflow-release` 可验证并生成安装包。主分支推送会自动发布 `BrushFlow_v版本号` 标签及小写同名 ZIP；发布资产只包含插件运行模块、文档和构建产物，不包含测试、依赖目录或本地备份。
