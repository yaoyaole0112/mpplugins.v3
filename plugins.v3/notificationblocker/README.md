# 通知消息屏蔽 NotificationBlocker

按设置的正则关键词，对标题或正文命中的消息**不进行渠道推送**（TG/微信等不发送），
但消息中心历史仍保留，可在 Web 端查看。

内置**通知汇总**功能：按设定的定时时间（cron），发送今日各类型统计，并自动整理、
合并剧集通知；汇总只显示分类摘要，不展开每条通知的原文和正文。

## 工作方式

插件注册到 MoviePilot 的通知发送入口（共享拦截链 `_hookchain`，与「通知合并」插件
共用，二者可同时启用、互不干扰）：

1. 消息进入发送入口时先渲染出最终标题/正文；
2. 标题或正文命中任一正则关键词 → 写入消息中心历史后拦截，**渠道不再推送**；
3. 未命中 → 放行，按正常流程发送（或交给「通知合并」处理）。

优先级上屏蔽先于合并：被屏蔽的消息不会进入合并队列。

## 通知汇总

开启「通知汇总」并填写 cron 定时表达式（默认 `0 20 * * *`，每天 20:00），
到点会发送汇总通知，统计**今天写入消息中心的通知**按消息类型分组计数，
并将相同剧集、年份、季和结果的连续集数合并，例如：

```
📦 分类明细
1. 【大哥小助理 (2026)】 S01 E01-04 入库失败！ ×4
2. 【藏锋 (2026)】 S01 E02-E13 入库失败！ ×12
```

非剧集通知按标题归类；汇总不展示原文、正文和链接，同组来源会去重显示。
汇总内容超过单条通知限制时会自动拆分为多条，标题会显示“第 x/y 部分”，不会再固定只显示前 20 条。

示例统计格式：

```
今日屏蔽通知汇总（54 条）
统计时间：2026-08-26

累计屏蔽：54 条

📊 类型统计
插件：22 条
整理入库：15 条
资源下载：8 条
站点：3 条
```

汇总消息绕过屏蔽/合并直接发送，不会被自己的关键词规则拦截。也可通过
`GET /api/v1/plugin/NotificationBlocker/send_summary`（需 API Token）手动触发。

## 配置项

| 配置项 | 说明 | 默认值 |
| --- | --- | --- |
| 启用通知屏蔽 | 屏蔽功能总开关 | 关 |
| 屏蔽关键词 | 正则表达式，每行一个；标题或正文命中即屏蔽 | 空 |
| 通知汇总 | 开启每日通知条数汇总 | 关 |
| 汇总定时 | cron 表达式（分 时 日 月 周） | `0 20 * * *` |

正则示例：

```
^【站点 某站】   # 标题以该前缀开头
垃圾|广告        # 包含"垃圾"或"广告"
```

无效的正则表达式会被忽略并在 MP 日志中提示；无效的汇总 cron 会导致汇总关闭并记日志。

## 说明

- 屏蔽的消息仍会写入消息中心历史（与原始发送行为一致），仅渠道不推送；
- 汇总统计范围为当天 00:00 至触发时刻（本地时区），按消息类型和内容归类；
- 从 1.3.0 起会保存每条被屏蔽通知的标题、正文、来源、链接和时间；
- 1.2.0 以前的数据只有去重标题，升级后可继续查看标题，但旧正文和重复记录无法恢复；
- 与「通知合并」插件共用共享拦截链，可同时启用；
- 插件源码位于容器 `/app/app/plugins/NotificationBlocker`，属容器层，
  `docker compose up -d` 重建容器后会丢失，需重新安装。
