# 订阅用户修正

监听 MoviePilot V3 的「新增订阅」事件，将**新建电视剧订阅**中由插件填入的订阅用户（如“猫眼订阅”）改为指定的 MoviePilot 用户名。不会改动电影、音乐、已有订阅，也不会覆盖归属于真实用户的订阅。

安装后在插件配置中开启自动修正。只有一个启用的 MoviePilot 用户时，“目标 MoviePilot 用户名”可以留空；有多个用户时必须填写目标用户名。后台事件没有当前网页登录会话，因此插件不会根据最后登录的人猜测归属。

此插件不会修改创建订阅的插件配置，也不会回写历史记录或发送的通知。如果其他插件后续再次主动修改同一条订阅的 `username`，本插件不会在「新增订阅」事件之外覆盖它。
