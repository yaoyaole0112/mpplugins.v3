# 订阅用户修正

监听 MoviePilot V3 的「新增订阅」事件，并按配置的 Cron 周期检查**全部已有订阅**（电视剧、电影、音乐及其他类型，包含所有状态）。凡订阅用户与目标 MoviePilot 用户名不一致，都会改为目标用户；默认每 30 分钟检查一次。

安装后在插件配置中开启自动修正。只有一个启用的 MoviePilot 用户时，“目标 MoviePilot 用户名”可以留空；有多个用户时必须填写目标用户名。后台任务没有当前网页登录会话，因此插件不会根据最后登录的人猜测归属。**本功能会修改原本归属于其他真实用户的订阅**，多用户部署应谨慎配置。

插件仅更新订阅记录的 `username`，不会修改订阅其他字段、创建订阅的插件配置、历史记录或已发送的通知。如果其他插件再次修改归属，下一次定时检查会重新校正。
