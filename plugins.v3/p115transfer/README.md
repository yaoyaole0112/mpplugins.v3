# 115转存/离线

插件标识为 P115Transfer，源码目录及日志来源为 p115transfer。

通过 MoviePilot 已配置的 Telegram Bot 接收链接，并调用 115 接口完成操作：

- 115 分享链接：解析分享码和 4 位提取码，转存分享根目录到指定 115 目录。
- magnet、ed2k、HTTP(S) .torrent：提交 115 离线下载任务到指定目录。
- 支持 /p115 链接、/offline 链接、/ns 链接，也支持直接发送链接。

## 配置

1. 在 MoviePilot 插件设置中启用插件。
2. 在115网盘STRM助手中登录。本插件自动读取其 cookies 配置，每次任务前刷新，不再提供独立 Cookie 输入框。
3. 填写目标目录，例如 /媒体/115离线；目录不存在时插件会请求 115 自动创建。已有目录设置不会自动修改。
4. 使用 MP Bot 时，保持自定义 Bot Token 为空；使用独立 Bot 时填写 Token 和允许的 Telegram 用户数字 ID（逗号分隔），仅处理白名单用户的私聊。可选填写 HTTPS 代理。
5. 目标目录支持绝对路径，或填写目标目录 CID（优先于路径，0 表示根目录）。分享转存和离线下载都使用此目标。

## 1.2.0

插件类、配置前缀、动作ID、源码目录和日志来源统一为 P115Transfer / p115transfer。旧版需先停止旧实例，再迁移配置和Bot游标到新实例，禁止同时运行两个接收端。历史日志作为审计记录保留，不改写旧日志。

115错误码10008按任务已存在处理，回复普通提示，不报提交失败、不重试、不改变已有任务目录。批量结果分别统计新增、已存在和失败。Bot回复发送失败不再被混淆为任务提交失败。Telegram短暂超时继续自动恢复。

## 1.1.3

单链接使用Web单任务接口，多链接使用Web批量接口，不再依赖客户端的默认SSP通道。支持转发文字中包含空格文件名或整体URL编码的ed2k链接，提交前校验文件大小和哈希。新增分阶段失败提示和115错误码，区分目录读取、目录创建及离线提交，批量结果按逐项成功/失败统计，不将空结果误报为成功。错误文本仅使用固定分类和数字错误码，不返回原始响应、完整链接、Cookie或Token；不自动重放提交。

统一展示名称及日志正文，默认目录改为 /115离线，公开命令改为 /p115、/offline、/ns。保留内部插件标识及配置字段以兼容已安装实例；已有网盘路径不自动搬迁。

## 1.1.2

修复Bot启动检查遇到ConnectError就永久退出：启动检查和消息轮询统一自动重连，30秒起递增退避，最长300秒，可随时停用取消。插件代理留空时复用MoviePilot网络代理；填写时优先使用插件代理。代理必须从MP容器内可达，127.0.0.1是容器自身。状态接口提供脱敏连接错误及代理来源，恢复后清除错误；不输出Token或代理密码，不重放网盘提交。Token认证失败、接收冲突及已有webhook仍停止监听，需修正配置。

## 1.1.0

新增 STRM 助手 Cookie 复用、独立 Bot 长轮询、私聊用户白名单、代理及目标 CID。独立 Bot 不应与 MP 或其他服务共用接收端；检测到 webhook 或接收冲突时停止监听，不自动删除 webhook。轮询游标按 Bot 隔离持久化，任务执行前推进，提交失败或进程中断不会自动重放；不保证任务必达，请根据回复核实。停用/重新配置会停止旧监听。

离线提交成功不代表下载完成。Token 只保存在插件配置中，请保护 MoviePilot 配置及备份；状态 API 不返回 Token 或 Cookie。

本插件不把 Cookie、消息正文或完整链接写入日志。转存前请确认你拥有相关内容的合法访问和存储权限。
